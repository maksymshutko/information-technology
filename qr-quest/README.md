# QR-квест «Цифрова грамотність»

**Київський професійний ліцей транспорту (КПЛТ) · 23–27 листопада 2026**

15 QR-кодів по ліцею → запитання → облік у Google Таблиці → спільний ТОП-10. Грати можуть усі; при реєстрації — прізвище, ім’я та група або посада (фільтруйте в таблиці).

Відповіді приймаються до 27.11.2026 включно (за київським часом). Обмеження на старт навмисно
не ввімкнене, щоб можна було зробити тестовий прогін; після тесту не забудьте очистити аркуші.
Повний список учасників і всіх відповідей завжди є в Google Таблиці, на сайті видно лише ТОП-10.

| Файл | Що це |
|---|---|
| `index.html` | Сторінка квесту: реєстрація, запитання, прогрес |
| `rating.html` | Рейтинг (на телефоні — вкладки, на великому екрані — дві колонки, оновлення щохвилини) |
| `print.html` | Генерація та друк QR-табличок (2 на аркуш А4) |
| `config.js` | Сюди вставляється адреса Apps Script |
| `apps-script/Code.gs` | Серверна частина + **15 запитань і правильні відповіді** |

> ⚠️ Папка `apps-script/` додана в `.gitignore` і **не потрапляє на GitHub**: репозиторій публічний,
> а в `Code.gs` лежать відповіді й секретні ключі точок. Код живе лише у вашій Google Таблиці.

## Підключення (≈10 хв)

1. **Таблиця.** Створіть нову Google Таблицю, напр. «QR-квест 2026».
2. **Скрипт.** Меню *Розширення → Apps Script*. Видаліть приклад і вставте весь `apps-script/Code.gs`.
   Змініть `ADMIN_KEY` на свій пароль. За бажанням вкажіть `START_DATE` / `END_DATE`.
   Збережіть (Ctrl+S).
3. **Розгортання.** *Розгорнути → Нове розгортання → Веб-застосунок*:
   - Виконувати від імені: **Я**
   - Доступ: **Будь-хто**

   Дозвольте доступ (Google попередить, що застосунок неперевірений — *Додатково → Перейти*).
   Скопіюйте URL виду `https://script.google.com/macros/s/…/exec`.
4. **Сайт.** Вставте цей URL у `config.js` → `QUEST_SCRIPT_URL = '…'`, зробіть commit і push.
   Через хвилину-дві сторінка буде на `https://maksymshutko.github.io/information-technology/qr-quest/`.
5. **Друк.** Відкрийте `…/qr-quest/print.html`, введіть `ADMIN_KEY`, натисніть «Згенерувати» → «Друкувати».
   У діалозі друку: А4, без полів, масштаб 100 %, увімкнути «Фонові зображення».

> Якщо пізніше змінюєте `Code.gs` — *Розгорнути → Керувати розгортаннями → ✏️ → Версія: нова*.
> Тоді URL лишається тим самим.

## Що з’явиться в таблиці

- **Учасники** — ID, прізвище, ім’я, категорія (тепер завжди «Учасник»), роль (порожня), група / посада, час реєстрації.
- **Відповіді** — час, хто, точка, тема, обрана відповідь, «так/ні».

Аркуші створюються автоматично під час першої реєстрації. Для підсумків можна просто
відфільтрувати «Відповіді» або відкрити `rating.html`.

## Захист від хитрощів

- Правильні відповіді є тільки в Apps Script — у коді сторінки їх немає.
- Кожен QR має секретний ключ (`k=…`): змінити `p=7` на `p=8` в адресі не вийде.
- На кожну точку — одна відповідь (перевіряється на сервері).
- Якщо людина реєструється вдруге з тими самими даними (інший телефон, очищений браузер), їй повертається той самий профіль із прогресом.
- При рівній кількості правильних вище той, хто раніше дав останню правильну відповідь.

## Чекліст організатора

- [ ] Перевірити та за потреби відредагувати 15 запитань у `Code.gs`
- [ ] Погодити з адміністрацією місця для 15 QR; вписати їх у поле `place` (видно лише на табличці дрібним шрифтом)
- [ ] Перевірити, що в цих місцях є Wi-Fi або мобільний інтернет
- [ ] Надрукувати, заламінувати / вкласти у файли таблички
- [ ] Тестовий прогін: 2–3 людини проходять кілька точок, дивимося таблицю й рейтинг
- [ ] Очистити аркуші «Учасники» та «Відповіді» після тесту (видалити рядки, крім заголовка)
- [ ] Оголошення: правила, терміни, призи (окремо студенти / працівники)
- [ ] Вивести `rating.html` на екран у холі
- [ ] Після завершення — нагородження, грамоти

## Демо-режим

Поки `QUEST_SCRIPT_URL` порожній, сторінки працюють із 3 тестовими точками, а дані зберігаються
лише в браузері. Посилання для перевірки: `index.html?p=1&k=demo1` (а також `demo2`, `demo3`).
