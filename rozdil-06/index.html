Векторна графіка

Чим векторне зображення відрізняється від растрового, які програми для нього є та як в Adobe Illustrator малювати й редагувати об’єкти.

7 тем
🃏 Картки розділу
01Суть векторного малюнка і його особливості▼

Векторне зображення складається з геометричних об’єктів — ліній, кривих, фігур, — описаних математично. Тому його можна масштабувати без втрати якості: логотип однаково чіткий і на візитці, і на білборді. Векторна графіка ідеальна для логотипів, іконок, схем і шрифтів, але не для фотографій.

Ключові поняття

Вектор
зображення, описане формулами кривих і фігур
Крива Безьє
крива, яку задають опорні точки та напрямні
SVG, AI, EPS, PDF
векторні формати файлів

Корисні ресурси

  • The Bézier Game — гра: навчись працювати з кривими Безьє

Інструменти

Inkscape
02Огляд програм для роботи з векторною графікою▼

Професійний стандарт — Adobe Illustrator. Безкоштовні альтернативи: Inkscape (комп’ютер), Figma (браузер, зручна для інтерфейсів і іконок), Affinity Designer. Для простих задач підійде онлайн-сервіс Canva або Boxy SVG.

03Особливості налаштування розмірів графічного зображення в програмі Adobe Illustrator▼

Під час створення документа задають розмір монтажної області, одиниці виміру (мм для друку, пікселі для екрана) та колірну модель: CMYK для друку, RGB для екрана. Розміри об’єктів змінюють на панелі «Трансформування»; щоб не спотворити пропорції, вмикай значок ланцюжка.

Блид (виліт)
запас 2–3 мм за краєм для друку

04Практична робота: Створення графічного малюнку у векторі в програмі Adobe Illustratorпрактична▼

Намалюй векторний малюнок (іконку, емблему чи предмет своєї професії) з простих фігур: прямокутник, еліпс, багатокутник, лінії. Збережи файл у форматі .ai та експортуй у PNG.

Інструменти

Adobe IllustratorInkscape
05Робота з об’єктами: малювання, зміна, розфарбування в програмі Adobe Illustrator▼

Основні інструменти: «Перо» для кривих, фігури, «Олівець», «Виділення» та «Пряме виділення» для зміни форми. Об’єкт має заливку і обведення — кожному можна задати колір, градієнт чи візерунок. Панель «Обробка контурів» (Pathfinder) поєднує фігури: об’єднання, віднімання, перетин.

об’єднання кількох об’єктів для спільного редагування

06Практична робота: Створення набору ярликів з дотриманням стилюпрактична▼

Створи набір із 5–6 ярликів (іконок) для теми своєї професії в єдиному стилі: однакова сітка розміру, товщина ліній, палітра й ступінь деталізації.
