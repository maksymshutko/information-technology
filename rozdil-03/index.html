Системи керування базами даних

Як влаштовані бази даних, чому таблиці зв’язують між собою та як у СКБД Microsoft Access створювати таблиці, форми, шукати й фільтрувати записи.

9 тем
🃏 Картки розділу
01Система управління базами даних Microsoft Office Access▼

Microsoft Access — настільна СКБД, яка входить до пакета Microsoft 365. Файл бази (.accdb) містить усі об’єкти: таблиці, запити, форми та звіти. Вікно Access складається зі стрічки інструментів, області переходів (список об’єктів) і робочої області.

Ключові поняття

СКБД
програма для створення баз даних і роботи з ними
Область переходів
панель зі списком об’єктів бази
.accdb
формат файлу бази даних Access

Корисні ресурси

  • Microsoft Access — сторінка продукту та навчальні матеріали

Інструменти

Microsoft AccessLibreOffice Base (безкоштовна альтернатива)
02Системи керування базами даних, їх призначення▼

База даних — це впорядкований набір даних про певну предметну область: клієнти СТО, склад запчастин, розклад рейсів. СКБД дозволяє створювати структуру бази, вводити й змінювати дані, шукати потрібне та захищати дані від втрат. Бази даних працюють за майже кожним сайтом і застосунком — від інтернет-магазину до Нової пошти.

Ключові поняття

База даних
організована сукупність даних про предметну область
Предметна область
частина реального світу, яку описує база
Настільна / серверна СКБД
Access, LibreOffice Base / MySQL, PostgreSQL

Корисні ресурси

  • Вікіпедія: Система керування базами даних — види СКБД і приклади

Інструменти

LibreOffice Base
03Реляційні бази даних, їхні об’єкти▼

У реляційній базі дані зберігаються в таблицях, пов’язаних між собою. Рядок таблиці — запис (один об’єкт), стовпець — поле (одна властивість). Первинний ключ однозначно визначає запис, а зовнішній ключ зв’язує таблиці. Основні об’єкти Access: таблиці, запити, форми, звіти.

Ключові поняття

Запис
рядок таблиці — дані про один об’єкт
Поле
стовпець таблиці — одна властивість
Первинний ключ
поле з унікальними значеннями для кожного запису
Зв’язок «один-до-багатьох»
одному запису першої таблиці відповідає багато записів другої

Корисні ресурси

  • W3Schools SQL — інтерактивний підручник мови запитів SQL

Інструменти

SQLite Online
04Створення таблиць бази даних▼

Таблицю зручно створювати в режимі конструктора: задаємо ім’я поля, тип даних і властивості (розмір, формат, обов’язковість). Правильно підібраний тип даних (короткий текст, число, дата/час, грошовий, так/ні) захищає від помилок введення. Не забудь призначити первинний ключ.

Ключові поняття

Режим конструктора
режим налаштування структури таблиці
Тип даних
вид значень, які можна зберігати в полі
Лічильник
тип поля, що автоматично нумерує записи

Корисні ресурси

  • Довідка Microsoft Access — офіційні інструкції зі створення таблиць

Інструменти

Microsoft Access
05Практична робота. Робота з об’єктами бази данихпрактична▼

Створи базу даних для своєї професії (наприклад, «Автосервіс» або «Кафе»): дві-три таблиці, первинні ключі, зв’язки між таблицями. Перевір, що кожна таблиця відкривається, а зв’язки показано у схемі даних.

Ключові поняття

Схема даних
вікно Access, де видно таблиці та зв’язки між ними

Інструменти

Microsoft Access
06Ведення і редагування даних різних типів▼

Дані вводять у режимі таблиці або через форму. Під час редагування можна додавати, змінювати й видаляти записи, копіювати значення. Маска введення та умова на значення допомагають уникнути помилок (наприклад, номер телефону в правильному форматі). Видалення записів у базі незворотне — будь уважним.

Ключові поняття

Маска введення
шаблон, за яким вводяться дані (телефон, дата)
Умова на значення
правило, яке перевіряє введені дані
Підстановка
вибір значення зі списку замість ручного введення

Інструменти

Microsoft Access
07Практична робота. Створення бази даних у середовищі СУБД, створення форм і введення данихпрактична▼

Створи форму для зручного введення даних у свою таблицю за допомогою майстра форм, налаштуй її вигляд і внеси щонайменше 10 записів.

Ключові поняття

Форма
об’єкт для зручного введення та перегляду записів по одному
Майстер форм
покроковий помічник створення форми

Інструменти

Microsoft Access
08Впорядкування, пошук і фільтрування даних▼

Сортування впорядковує записи за зростанням або спаданням значень поля. Пошук знаходить потрібний запис, а фільтр показує лише записи, що відповідають умові (наприклад, усі авто марки «Renault»). Для складних і повторюваних відборів створюють запити.

Ключові поняття

Сортування
впорядкування записів за значенням поля
Фільтр
тимчасове приховування записів, що не відповідають умові
Запит
збережене правило відбору й обчислення даних

Корисні ресурси

  • W3Schools SQL: WHERE та ORDER BY — як фільтрують дані мовою SQL

Інструменти

Microsoft Access
