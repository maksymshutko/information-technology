# information-technology
Сайт курсу «Інформатика» — Київський професійний ліцей транспорту.

Структура: `index.html` (11 розділів) → `rozdil-01/` … `rozdil-11/` (теми, конспекти, ресурси, інтерактиви).
Презентацію до теми можна вбудувати: у `rozdil-NN/index.html` знайди потрібну тему й встав посилання Google Диска/Slides у `data-src=""` блоку `<div class="slides">`.
